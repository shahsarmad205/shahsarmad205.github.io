# Portfolio Site

This repository contains a simple portfolio website.

## Structure

- `index.html` - main HTML document for the site.
- `style.css`  - styling for the site.
- `script.js`  - small script for dynamic behaviour.

## Viewing Locally

Open `index.html` in a web browser. For example:

```bash
# from repository root
after cloning
open index.html # on macOS
# or
xdg-open index.html # on Linux
```

Alternatively, use a local HTTP server:

```bash
python3 -m http.server
# then navigate to http://localhost:8000
```

## Running Tests

This repository currently does not include automated tests. If tests are added,
run them using the command appropriate to the framework in use (for example,
`npm test` for a Node-based setup).
